# 参考スライドの選び方

参照するのは「見せ方」であり、過去提案の本文ではない。各目標スライドについて、次の優先順で近い例を選ぶ。

1. スライドの役割: 表紙、課題整理、比較、概念図、導入ロードマップ、効果、画面モック
2. 読み手と用途: 経営判断、現場説明、営業提案、PoC 合意
3. レイアウト: 左右比較、3カラム、ステップ、カード、表、主役画面
4. 情報密度: 大きな主張だけか、根拠・注釈・表を要するか

流用してよいものは構図、読み順、文字量、図版の役割、トンマナである。固有名詞、数値、顧客課題、結論、ロゴ、機密情報は流用しない。近いサンプルがない場合は、デッキ内で同じ役割のページとの一貫性を優先する。
